# 全文核查第二批：证据、反例与缺口

核查日期：2026-10-11。本文把 18 条新记录与第一批 4 条合计为 22 条“有全文定位的研究问题”。它们是用于继续查证的候选，不是 22 项已经证实的研究空白，更不是重要性排名。每条数据含 arXiv 版本、全文小节、来源主张和可区分假设；详见 `data/audited_research_questions_batch2.jsonl`。

## 目前最清楚的发现

1. **结论高度依赖评价条件。** FairFuzz 的覆盖率结果并不能直接代表 bug 发现；FuzzBench 独立比较中，FairFuzz 的总体 bug efficacy 与“单位时间多找 distinct crashes”并不一致。代码不确定性也类似：表征方法、代码任务和模型不同，结论会变；因此应比较风险排序/校准/拒答成本，而不能只问“uncertainty 是否有效”。

2. **基准论文报告的优势，不能自动外推。** SWE-bench 明确是 Python 任务，且测试通过不保证补丁完整、可读或高效。[SWE-bench §7](https://arxiv.org/html/2310.06770)；OSWorld 的鼠标定位错误来自特定失败样本，软件知识、弹窗和视觉 grounding 也会导致失败。[OSWorld §5.4](https://arxiv.org/html/2404.07972)；CodeMirage 的 1,137 个幻觉片段来自 GPT-3.5、Python、HumanEval/MBPP，检测结果不能当作跨语言结论。[CodeMirage §§3–5](https://arxiv.org/html/2408.08333)

3. **有些论文给出的是可测的研究方向，不是干预已奏效的证据。** OK-Robot 作者把动态地图和失败检测/恢复列为开放问题；因此我们把它们转成实验问题，不写成已有方法已经提高成功率。[OK-Robot §V](https://arxiv.org/html/2401.12202)

4. **目前看得到一个真正有用的条件性反例。** AgentWorld 中，固定共享计划但禁止交流的成功率是 17.6%，无交流基线是 22.9%；默认多 agent 交流为 52.0%。在这个基准上，共享计划本身不够，允许交流、核对进度和修正计划似乎更关键。[AgentWorld §4.4](https://arxiv.org/html/2609.31590) 这不是普遍定律，但足以把原问题从“共享状态是否有用”改成“共享状态在什么更新/沟通条件下才有用”。

5. **上下文与测量边界值得拆开。** VRpilot 在其 C 与 Java 数据上报告比基线多 14% 和 7.6% 的正确补丁，组件消融支持 reasoning 与 patch feedback 的贡献；但作者也指出人工判断正确性成本高、训练数据泄漏无法完全排除。[VRpilot §§4–5](https://arxiv.org/html/2405.15690) npm 研究发现其抽样项目里大量安全告警不涉及 production dependencies，但这是特定项目样本的 scope-filtering 机会，不等同于 reachability 分析能保持漏洞召回率。[NPM study §§4–7](https://arxiv.org/html/2207.14711)

6. **能耗结论受硬件和测量设置约束。** Sustainable NLP 论文直接列出受控环境、有限任务域和硬件差异等局限；它还报告能耗追踪本身会增加开销。因此下一步指标应是“固定质量下每个成功任务的焦耳数”，不能只报每 token 能耗。[Sustainable NLP, Limitations](https://arxiv.org/html/2502.05610)

## 记录范围与可信度

- 第一批 4 条 + 本批 18 条 = **22 条全文定位问题**；本批有 **19 次来源引用、18 篇不同来源**。全文定位指核到所列 arXiv HTML 版本中的相关章节，不意味着已穷尽该主题的所有文献。
- 证据强度不同：有的是多个条件的结果差异；有的是单篇基准/案例研究；有的是作者提出的 future work。记录中的 `evidence_status` 明确标注“独立复现/反向证据仍待查”，不把它们混为一谈。
- AgentWorld 和多项近期基准的时间版本很新；本结果是截至 2026-10-11 的快照，仍需固定版本并追查后续论文。
- 这一步没有把候选池的 2,106 篇去重论文全部读完，也没有宣称找到了领域里“所有论文”。此前大库按年份×主题筛出的 2,106 个唯一候选，是接下来扩大对照证据的起点；需要逐题再做引用追踪、近十余年历史分层和阴性结果检索。
