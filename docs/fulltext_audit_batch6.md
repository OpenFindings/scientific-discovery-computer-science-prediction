# 全文审查批次 6：早期随机样本的跨领域补空

审查日期：2026-10-11。前四项均从固定抽样框 `data/fulltext_stratified_sample.jsonl` 的 2010–2014 uniform-random arm 选出；第五项是聚类论文的引用追踪，不计入随机抽样覆盖率。PDF 全文按下面列出的证明/实验/结论章节核对。

## 1. Formation Control with Pole Placement for Multi-agent Systems（arXiv:1305.3797v1；随机样本）

- §§II、IV：作者研究连续时间、单积分器、线性 leader–follower 系统。定理 2.4 的正文条件是 leader 为根的有向生成树，且图无有向环；在此条件下可用局部反馈参数指定实闭环极点，并通过邻居间权重编码目标编队。每个体只需已知局部相对位置。注意摘要的简写没有列出“无有向环”这一附加条件，正式结论应以定理为准。
- §V：给出小规模矩阵/图例，包括有环图下增益非唯一以及可实现复极点的示例；这是算例，不是物理机器人实验。
- §VI：作者将“有向环是否有助于、以及是否为任意极点配置所必需”列为开放问题。核心结果限于理想模型、固定拓扑和线性控制；没有噪声、时延、非线性动力学或实机验证。

## 2. Automated Code Generation for Lattice Quantum Chromodynamics and beyond（arXiv:1401.2039v1；随机样本，但对 AI 子领域属于边界/误命中）

- arXiv PDF 标注 primary category 为 hep-lat。QIRAL 是面向格点量子色动力学的领域专用语言/规则式编译工具：从结构化 LaTeX 算法描述生成 OpenMP C；文中没有机器学习/AI 代码生成方法。因此它属于广义自动代码生成，不应作为“AI 生成代码”实证论文计数。
- §§2–5、结论：展示 DSL、规则重写/类型检查、算法与预条件组合，并把生成程序与 tmLQCD、手工调优库/不同 CPU 与 Xeon Phi 比较。测试涉及特定 LQCD 共轭梯度与 Schur 预条件任务。作者报告若干架构上性能有竞争力；NUMA/跨芯片拓扑会显著影响扩展性：Nehalem-EX 32 核前效率高于 95%，之后因互连开销快速下降。
- 证据边界：这是特定物理领域 DSL/编译器论文，不是通用代码生成或模型评测；优化库、硬件、数据布局影响结果，不能把“自动生成更安全/缩短开发时间”当成经对照实验验证的结论。

## 3. Efficient Clustering with Limited Distance Information（arXiv:1009.5168v2；随机样本）

版本核对：首次审读记录误写为 v1；抽样框指向 v2。现已直接复核 arXiv v2 全文 §§1–3、5.1–5.3、6，下面的定理条件、Pfam/SCOP 对照和参数敏感性结论均按抽样版本记录。

- §§1–3，定理 2：Landmark-Clustering 在近似稳定性 `(1+α, ε)`、目标簇足够大等假设下，用约 `O(k + log(1/δ))` 次 one-versus-all 距离查询得到接近目标聚类的结果；证明不是对任意度量空间和任意目标标签都成立。
- §§5.1–5.3：作者对 Pfam（按序列相似度定义的分类）和 SCOP（superfamily 标签还利用结构/生化证据）做蛋白序列实验。Pfam 大多数据集接近 gold labels，但数据集 7、9 是反例；SCOP 上准确性明显较差，作者将其与“序列相似度不符合结构分类证据”联系起来。参数 `s_min` 敏感，需在实践中尝试；随机 landmark 重复后报告中位数。
- §6：作者明确把小簇上的可证明算法列为后续问题。论文比较受到可用距离信息的限制；不能将其结果理解成少量查询在所有聚类任务上都足够。

## 4. Opening the Black Boxes in Data Flow Optimization（arXiv:1208.0087v1；随机样本）

- §§3–6：PACT/Stratosphere 数据流优化器从 imperative UDF 的静态代码分析抽取读/写属性，以证明安全的 operator reorder 条件，再枚举候选计划。它优化的是允许重排的条件，不需要完整代数语义；安全可重排不等于重排一定更快。
- §7：TPC-H Q7 枚举 2,518 个计划，最慢抽样计划约 45 分钟、最低成本计划约 6 分钟；文本挖掘示例的最优/最差抽样计划也相差近一个数量级。运行时结果每计划平均 3 次；静态分析在表列四个任务上恢复了手工注解替代计划数的 75%（clickstream）或 100%（其他三项）。朴素枚举耗时在这些任务中低于 1.654 秒。
- 边界：§7.3 限制包括原型系统不支持索引/列存/物化视图、全表扫描，以及计划枚举尚未做高效剪枝；静态分析只掌握编译时可见字段访问等信息。§9 将 selectivity/算子成本估计列为未来工作。少数工作负载的高收益不能当作总体性能保证。

## 5. Min-Sum Clustering of Protein Sequences with Limited Distance Information（SIMBAD 2011；引用追踪，非独立复现）

- 这是与 2010 随机样本同一作者团队、同一蛋白序列评估语境下的 objective 变体，不是独立团队复现。该工作改用 min-sum/平衡 k-median 稳定性条件；定理还要求目标簇有足够大的规模，且理论参数与最优目标值有关。
- §5：沿用原论文数据并把查询预算设为相同的每簇约 30k 次。Min-Sum 版本在 Pfam 数据集 7、9（原方法表现不佳处）倾向更好，但多数 Pfam 数据集没有胜过原 Landmark 方法；SCOP 上三种方法表现相近。作者指出结构标签与序列相似度不总一致，也说明算法的可行性和标签质量会与数据结构/目标度量相互作用。
- 解释边界：同团队、同数据，不是外部验证；有限 benchmark 与人工设置参数不能证成一个可普遍推广的“自动选择目标函数”方案。

## 暂定可证伪问题（聚类；非新颖性结论）

能否用不依赖 gold labels 的数据诊断，在少量距离查询下判断某数据集是否符合 Landmark k-median 的分离/稳定性条件；若不符合，系统能否在 k-median、min-sum 与 abstain 之间做选择，从而比固定用一种目标函数更稳定？可用公开 Pfam/SCOP 版本与其他相同任务标签集，预注册诊断阈值，在按蛋白家族隔离的划分上比较标签误差、距离查询数、覆盖率和拒答率。关键反例是标签依据与可用相似度不同源（如结构标签对序列距离）、大量小簇/离群点及跨版本数据漂移；训练/调参与测试家族必须隔离。
