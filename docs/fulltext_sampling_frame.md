# 全文分层审查框

生成日期：2026-10-11。脚本：`scripts/build_fulltext_sampling_frame.py`。

## 目标与抽样

输入是完整的 `data/research_candidates_uncapped.jsonl.gz`，该文件有 198,690 个不封顶 arXiv-CS 候选。脚本对 18 个子领域、4 个时期形成 72 个 topic × period 单元。这里的时期按 arXiv 首次提交年份，而不是期刊/会议首次发表年份；这只能给 arXiv 收录时间分层，不能直接代表学术成果年代。

抽查发现实际后果：`1106.0235` 于 2011 年上传 arXiv，但其元数据标注 JAIR 2000 年发表。要研究“十几年的进展”，后续必须为抽中论文额外核验 venue/year，并对经典出版物做引用追踪；仅靠这份 arXiv 时间框会把部分经典工作放错年代，也漏掉未上 arXiv 的成果。

每个单元分开选择：

1. 最多 3 篇确定性 hash 排序的均匀随机样本，用于估计词法候选筛选的相关率；
2. 最多 3 篇词法筛选分数最高的候选，平分时由确定性 hash 决定，用于提高全文发现效率。

种子为 `cs-literature-fulltext-frame-2026-10-11-v1`。截至生成日，72/72 单元非空；foundation_models × 2010–2014 单元只有 1 篇候选，其余单元最多各取 3 篇/组。结果是 428 条 cell-arm 记录、407 个去重 arXiv ID。完整元数据、摘要、词法分数、抽样组和 arXiv HTML/PDF 链接在 `data/fulltext_stratified_sample.jsonl`；单元分母和脚本规则在 `data/fulltext_stratified_sample_profile.json`。

## 解释边界

- 抽样框不是 428 篇已读论文；每条必须抓取并核实所列版本全文、发表版本、研究问题、结果、限制和独立反例。
- 随机组和词法优先组不得混在一起估计命中率。随机组较适于估算筛选误差；词法优先组故意过抽高 gap-cue 分数，不能代表领域分布。
- 论文可跨 topic，因此 428 条 cell-arm 记录只有 407 个唯一 arXiv ID。统计论文数时按 base arXiv ID 去重，统计领域覆盖时保留 topic 归属。
- 这是候选库的可审计样本，不等于全领域抽样。非 arXiv venue-only 工作、词法规则漏掉的论文和 2026-10-11 之后论文都不在框内。

## 后续执行规则

逐批处理完整抽样框，优先确保每个时期/子领域都有全文核查，然后做引用追踪和反例检索。每篇记录：全文是否可得、版本/venue、是否与词法 topic 真相关、研究问题、实验与结果、作者限制、独立支持/反证、可证伪后续问题。若抓不到全文，明确标记，不得仅凭摘要升级为发现。每批完成后更新 JSONL 与覆盖剖面，保持随机与优先组分开。
