# Literature review

This is an initial evidence map, not a completed novelty claim. The repository contains no source bibliography and the requested OpenFindings pages were not retrievable through the available browsing path on 2026-10-11. Before final evaluation, collect and archive primary sources for:

- autonomous scientific discovery and AI Scientist systems;
- active learning and Bayesian experimental design;
- agentic software engineering, automated debugging, and program repair;
- reproducibility, falsification, and adversarial evaluation.

The review must record the exact paper version, code URL, licence, benchmark split, execution capability, and whether evidence is executed or merely generated. Search-derived summaries are insufficient for transferring methodology.
