# Paper 5 execution and falsification pilot

## Design

Four executable cases cover three fault mechanisms plus a context-dependent
confound. Five deterministic policies receive the same action catalog and a
maximum of three probe executions per case: direct fixed probe, fixed workflow,
one-step Paper 4 utility adapter, planner with feedback, and planner with an
explicit falsification step. A conclusion is resolved only above posterior
0.80 and after two distinct probe families. Each run records actual process
output, parsed result, posterior, duration, exit code, action cost, and whether
the falsification probe reduced support for the current leading hypothesis.

The planner adapter uses Paper 4's `configs/default.yaml` weights: information
gain 10, novelty 1, tractability 1, and cost 1. Its novelty calculation uses
unseen provenance roots and is recorded with every planner recommendation.

## Observed pilot results

| Policy | Correct resolutions | Correct provisional predictions | Unsupported provisional conclusions | Mean probes | Counterevidence events |
|---|---:|---:|---:|---:|---:|
| Direct | 0/4 | 1/1 | 0/4 | 1.00 | 0 |
| Fixed workflow | 3/4 | 3/4 | 0/4 | 3.00 | 0 |
| Paper 4 utility adapter, one action | 0/4 resolved | 3/4 | 1/4 | 1.00 | 0 |
| Planner with feedback | 3/4 | 3/4 | 0/4 | 2.25 | 0 |
| Planner plus adversarial falsification | 3/4 | 3/4 | 0/4 | 2.25 | 1 |

For the resolved-rate estimate of 3/4, the descriptive 95% Wilson interval is
0.30–0.95; for 0/4 it is 0.00–0.49. The intervals are broad because this is a
four-case infrastructure pilot.

## Interpretation

The adversarial policy found one counterevidence event in the context-confound
case. A targeted boundary probe contradicted the initially leading diagnosis;
the system then withheld resolution. It matched feedback planning at 3/4
correct resolutions and 2.25 mean probes. This pilot therefore shows the
falsification path can execute, record a contradiction, and trigger abstention.
It does not show that an adversarial agent improves reliability over ordinary
feedback planning.

The one-step utility adapter made one unsupported provisional diagnosis on the
confounded case. The feedback and adversarial policies withdrew that diagnosis
after a second distinct probe. The probe outcomes share one software artifact,
so the Bayesian calculation assumes conditional independence that has not been
validated. Distinct test probes are not independent provenance roots.

## Limits

The comparison policies are deterministic algorithms, not LLM agents. A
provider interface now lets a model select registered action IDs, but no model
provider was available for this run. The benchmark is synthetic and contains
four cases. The result does not establish effectiveness
on SWE-bench, BugsInPy, Defects4J, public bug reports, or scientific questions.
There is one run per policy-case cell, no powered statistical comparison, and
no independent human adjudication. On this managed macOS host, nested
`sandbox-exec` was denied; the recorded run used the inherited Codex-managed
sandbox and process resource limits. A standalone evaluation requires a
supported OS/container isolation backend.

The result is a pilot engineering finding only: the falsification workflow is
operational and detected the deliberately introduced contradictory probe in
this fixture. Its scientific value remains unestablished.
