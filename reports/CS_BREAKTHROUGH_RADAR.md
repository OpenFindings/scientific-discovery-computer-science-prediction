## EDCS result (2026-10-15)

The selected action produced a real bounded negative result. The frozen deterministic lazy variant performed at most one H-edge repair per external update, with `beta=4` and `beta_minus=3`. Across all 530 static masks for k=1,2,3, all 79,209 K3,3 deletion prefixes of length up to 6, and one fixed mixed trajectory, the first failure was the four-insertion witness `(0,0),(0,1),(0,2),(1,0)`. It left used edge `(0,0)` with endpoint degrees 3 and 2, so P1 was violated at sum 5>4. The matching ratio was still 2/2=1.0.

This is a counterexample to the proposed lazy-repair rule, not to EDCS generally. Bernstein–Stein define the same P1/P2 degree-sum constraints but maintain them through a substantially different dynamic algorithm involving alternating paths and orientation/bucket information; their paper explicitly emphasizes the global effect of the local constraints. The [prior-art audit](edcs_prior_art_audit_20261015.json) and [independent validation](edcs_experiment_result_20261015.json) preserve that boundary. A fixed-witness derivation now proves the same obstruction for every integer `beta>=3` with `beta_minus=beta-1` under one single-edge toggle per update. An adversarial proof review also disproved the earlier overbroad claim that every P2-deficient edge must itself be inserted: an alternate unused edge can repair P2 when the parameter gap permits it. The corrected one-toggle impossibility lemma is fully proved only under its explicit assumptions. There is no general dynamic-EDCS lower bound, so this direction is closed as an independently verified educational/engineering result, not a publishable breakthrough.
